# Gentlemen English

Полная копия веб-приложения для iPhone: 1 520 карточек, три колоды, FSRS-повторение, персонаж, три локации, магазин и ручной экспорт/импорт прогресса.

## Приложение

Готовая версия находится в `dist/`. GitHub Actions публикует эту папку на GitHub Pages при каждом обновлении ветки `main`. Все изображения карточек и интерфейса лежат в `dist/assets/`; пути относительные, поэтому приложение работает и в подпапке GitHub Pages.

Для локальной проверки:

```sh
python3 -m http.server 8765 --directory dist
```

Откройте `http://localhost:8765/` на этом компьютере. Для установки на iPhone нужна HTTPS-страница GitHub Pages. В Safari: «Поделиться» → «На экран Домой».

## Прогресс

Прогресс хранится на устройстве в OPFS, отдельно для каждого адреса сайта. При переходе на GitHub Pages откройте в новом приложении «Профиль» → «Восстановить из файла» и выберите экспортированный ранее JSON. После сообщения «Прогресс восстановлен и сохранён» экспортируйте новую резервную копию. Файл прогресса нельзя добавлять в этот репозиторий: опубликованный сайт и его файлы доступны другим пользователям.

Идентификаторы существующих карточек в `dist/cards.json` должны оставаться прежними. При добавлении карточек добавляйте новые объекты с уникальными `id`, сохраняя все старые объекты. Запускайте `python3 scripts/validate_release.py` до публикации. Старый `scripts/build_cards.py` создаёт набор заново из внешних словарей и **не предназначен** для обновления нынешних 1 520 карточек.

## Изображения и аудио

Изображения находятся в сборке локально. Часть озвучки загружается из Wikimedia Commons, а для некоторых слов используется системный синтез речи iPhone. Основной интерфейс и карточки доступны из кеша после первой полной загрузки, но удалённая озвучка может потребовать интернет.
